# HackAlem Minutes

Локальный помощник секретаря совещания: запись → транскрипт → поручения → проверенный протокол.

## Статус

MVP в разработке. Первый этап — загрузка аудио/видео, локальное распознавание русской,
казахской и смешанной речи, проверка транскрипта, поручения и экспорт DOCX/PDF.
Интеграции с Teams, Zoom и Google Meet пока не реализованы.

## Ограничения проекта

- Аудио и текст обрабатываются локально, без внешних облачных API.
- Качество смешанной речи проверяется на тестовых записях; безошибочное распознавание не гарантируется.
- Имена, сроки и спорные фрагменты подтверждает пользователь.
- Реальные записи, персональные данные и `.env` не попадают в Git.
- Настройки документируются в `.env_example`.

## Воспроизводимость

По мере реализации здесь будут добавляться проверенные команды установки, загрузки моделей,
запуска и проверки основного сценария. На текущем стартовом коммите приложения ещё нет.

Целевая машина разработки: MacBook Air M2, 16 ГБ RAM. Предварительный стек: Python,
FastAPI, MLX Whisper, локальная языковая модель и SQLite.
