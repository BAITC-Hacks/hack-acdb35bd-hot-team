# Project rules

- Build a reproducible local meeting-minutes MVP for a five-hour hackathon.
- Repository: https://github.com/BAITC-Hacks/hack-acdb35bd-hot-team
- User has authorized commits and pushes. Save meaningful progress about every 50 minutes;
  do not exceed one hour between progress commits while actively developing.
- Never commit `.env`, credentials, real recordings, transcripts, or personal data.
  Keep configuration examples in `.env_example`.
- Audio and meeting text must not be sent to external inference APIs.
- Maintain README with exact setup, model download, startup and verification steps.
- Do not describe unimplemented integrations or simulated AI results as working features.
- Preserve Russian and Kazakh in transcripts. Flag uncertain owners and deadlines.
- Verify the main user flow and relevant error cases before delivery.
- Prioritize work against the jury rubric in docs/JURY_CRITERIA.md: value 25,
  outcome quality 20, innovation 15, growth potential 20, presentation/demo 20.
  Demonstrate measured outcomes; distinguish implemented capabilities from roadmap.
